# Sliding Window

## When to recognize it
- Contiguous subarray or substring
- Need maximum, minimum, count or longest range
- Window can be updated incrementally

## Questions to ask
- Is the window fixed or variable?
- What makes the window invalid?
- What information must I maintain?

## Common mistakes
- Moving the left pointer too late
- Recalculating the entire window
- Forgetting repeated values

## Problems to review
- Longest Substring Without Repeating Characters
- Minimum Size Subarray Sum
